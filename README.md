# Tucker Ritti's Homebrew tap

Install [AI Usage](https://github.com/tuckerritti/ai-usage-menu-bar), a macOS menu bar app showing Claude and Codex usage:

```sh
brew install --cask tuckerritti/tap/ai-usage
```

Requires macOS 14 or newer. Run `brew upgrade --cask tuckerritti/tap/ai-usage` to update.

The app's release workflow keeps this tap up to date.
